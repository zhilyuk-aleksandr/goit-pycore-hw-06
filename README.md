# Домашня робота 06 · Тема 9

Адресна книга зберігає контакти за іменем. Клас `Record` має обов’язкове поле `Name` і список полів `Phone`. Передавайте телефон рядком із десяти цифр, щоб зберегти початковий нуль. Для запуску достатньо Python 3.

З теки роботи запустіть приклад

```bash
python3 address_book.py
```

Результат після додавання двох номерів і заміни другого

```text
Contact name: Olena, phones: 0501234567; 0671111111
```

В іншому модулі імпортуйте `AddressBook` і `Record` з `address_book`. Для контактів доступні `add_record`, `find` і `delete`, для телефонів — `add_phone`, `find_phone`, `edit_phone` і `remove_phone`. Обидва методи пошуку повертають `None`, якщо збігу немає.
